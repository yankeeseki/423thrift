Keep this file on your computer. Do NOT upload it to GitHub. It used to live as a hidden comment at the top of index.html,
but anyone could read it there with "View Source" (it held sponsorship pricing, shop-manager names and unannounced plans),

WHAT THIS IS
Chattanooga Thrift Trail: a single-file map and route planner for thrift, vintage and antique shops.
Live at https://423thrift.com/ on GitHub Pages (repo "423thrift", custom domain via CNAME).
Leaflet + OpenStreetMap, OSRM routing, jsPDF, Firebase Firestore reviews, Google Analytics (G-6DXP5B81PJ).

FILES IN THE REPO
index.html (this file) | sw.js (offline) | manifest.webmanifest | CNAME | robots.txt | sitemap.xml
icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png, favicon.ico

shops/index.html (standalone "Shops & Charities" page for Google; the popup on the main page uses the same data)
How to deploy: open the file in GitHub, click the pencil, paste, commit (about a minute to go live). Reload twice.

WHERE THINGS LIVE IN THIS FILE
routeDefaults / bonusDefaults ... the shop data (hours, notes, area, category, closesAfter). Category sets the marker color.
SHOP_BENEFIT ................... which shops show the "Proceeds benefit" charity note (mirrored in shops/index.html).
isFeaturedToday() .............. gold-star Featured Shop: Poor Taste on Saturdays; Nifty Thrifty on Tuesdays; Chattanooga Room in the Inn on Sundays; Vinterest (Southside) the other days until it closes
                                 Dec 27 2026, then Vinterest (Hixson) from Dec 28 2026.
HOLIDAY_FUN / HOLIDAY_STARS .... daily banners. FUN = the owner's list of goofy days (tiny line). STARS = thrift days (prominent).
                                 Themed weeks before Christmas, Thanksgiving, Halloween, Easter. "Open" badge becomes
                                 "Check Hours" on major holidays. Never include Juneteenth, Pride or Black History Month.
addBackgroundBonus() ........... draws the faded gold diamonds (every shop not on the loop) and their More Shops cards; bonusPopupNode / offRoutePopupNode / shopPopupHtml build the map popups; addState() decides 'Add to Route' vs 'Closed today'.
dn() ........................... on-screen shop names (Fort O, and NNH shown as Northside Neighborhood House); the stored name is the key for saved data.
sub-page files .................. thrift-stores-*/index.html (neighborhood pages), calendar/index.html (community calendar; hard-coded special days in specials()), shops/update/index.html (shop managers form + shop-name datalist), menu.js (sub-page menu, footer, version line).
cttTrack(...) .................. Google Analytics events.
The bottom "days to mark on your calendar" list is separate static HTML (12 days).
